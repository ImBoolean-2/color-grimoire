Color Grimoire

Version 0.4.1 · Krita 5.3 / 6.0

Color Grimoire is a Krita docker for keeping each OC's colors, body-part notes, layer recipe and environment palette in one place. Click a swatch to set the foreground color; right-click to set the background.

Install

  1. Download grimorio_color-0.1.0.zip.
  2. In Krita: Tools → Scripts → Import Python Plugins, select the ZIP.
  3. Restart Krita.
  4. Settings → Configure Krita → Python Plugin Manager: enable Color Grimoire.
  5. Restart Krita again.
  6. Open the panel from Settings → Dockers → Color Grimoire.

On Linux you can also run bash install.sh from the release folder. The script detects the Flatpak and native Krita paths.

Optional personalization

  • OC photo: use Add photo in the sheet hero. It is copied to images/ next to the JSON and shown in the hero. Change, remove or open it with the buttons under the photo.
  • Zone example: the small ▣ button in each zone header adds a reference crop (hair base/shadow, painted skin, etc.). It appears in the zone with a Remove example button.
  • Color ramp: every zone with base, shadow and light colors shows an automatic shadow → base → light strip. It is a visual guide, not a replacement for the swatches.

Back up the JSON and the images/ folder together. The JSON alone does not carry the images.

First steps

  • Pick an OC in the dropdown, or create one with New OC.
  • The Sheet tab holds the summary, history, personality and relationships.
  • The Palettes tab has eight zones: skin, hair, eyes, clothing, armor, accessories, private and marks/scars.
  • Each color stores a name, HEX, role, body part, purpose, opacity and note.

Colors

  • Left click a color: foreground. Right click: background.
  • Apply color opacity uses the swatch alpha; leave it off to apply the color opaque.
  • Add creates a color in that zone; the pencil edits it; the cross deletes it.
  • The Private zone is hidden by default. Turn on Show private to reveal it. It is not encrypted; treat the JSON as private.
  • The Key strip at the top gives one-click access to the first skin, hair and eye colors.

Layer recipe

  • The Layers tab stores the stack from top to bottom: LINE, BASE, SHADOW, AO, LIGHT, GLOW, FX by default.
  • Each row has a blend mode, opacity and purpose. Use the arrows to reorder, the pencil to edit.
  • Create layers in Krita creates a group with the recipe's layers, blend modes and opacities in the active document. The layers are blank: they are a starting point, not a painted result.
  • Reset base restores the default recipe.

Environment

The Environment tab stores the scene name, time, weather, mood, key light, shadow tint, bounce color and an environment palette. Use it as the lighting recipe for the scene.

Scene preview and lighting rig

Scene preview shows the key skin, hair and eye colors tinted by the scene's key light, shadow and bounce. Click a chip to use that color.

Create lighting rig builds a group of fill layers with the environment colors: SHADOW (Multiply), AO (Multiply), LIGHT (Add), GLOW (Add) and BOUNCE (Add). The group inherits alpha to clip to the layers below. The layers are a color wash, not a painted scene; paint masks or adjustments on top.

Save the environment before creating the lights: the rig uses the saved values, not the unsaved form.

Color Guard

Enable Color Guard in the footer to compare the current foreground color with the active OC's palette. It shows the nearest swatch and the ΔE; if the color is off-palette, use Snap to set the exact palette color. The private zone is skipped while private mode is on. The ΔE threshold is a guide, not an absolute color-management check.

Web companion

The web button in the header (or ⋯ → Open web Grimoire) opens the web app in your default browser. The default target is ~/proyectos/grimorio-color/index.html; use ⋯ → Set web Grimoire… to set a local path, an http(s):// URL or a file:// URL.

The web app is not bundled in the plugin ZIP and uses its own localStorage. It does not sync automatically: use Export JSON in the plugin and Import JSON in the web app (and the reverse). The reference images and zone examples are preserved in the JSON fields, but the web app does not display the image files.

JSON and backup

Everything is stored in one JSON file. The menu ⋯ → Export JSON… makes a backup; Import JSON… restores one. Open data folder shows the file.

  • Linux Flatpak: ~/.var/app/org.kde.krita/data/krita/grimorio-color/grimorio.json
  • Linux native: ~/.local/share/krita/grimorio-color/grimorio.json
  • Windows: %APPDATA%\krita\grimorio-color\grimorio.json
  • macOS: ~/Library/Application Support/krita/grimorio-color/grimorio.json

Export .gpl writes a GIMP palette for Krita's Palette Docker. With private mode on, the Private zone is excluded from the file.

Language and custom translations

The panel follows the system language (Spanish or English). Change it any time in ⋯ → Language.

To add your own language: ⋯ → Language → Create translation template. Copy translation-template.json to <code>.json (for example fr.json), set code and name, and translate the values in strings. The keys are the Spanish source strings; empty or missing values fall back to Spanish. Use Reload translations or restart Krita. The files live in translations/ next to the JSON.

Community translations can also ship inside the plugin in grimorio_color/translations/; the plugin loads both and the user's files override the bundled ones. See CONTRIBUTING.md in the repository to send a language.

Privacy

No network, no accounts, no telemetry. The plugin only reads and writes the local JSON file and, when you ask, the palette/export files you choose. The Private zone is hidden in the UI but stored in the same JSON; back it up accordingly.

Troubleshooting

  • The plugin does not appear in the Plugin Manager: check that grimorio_color.desktop is in the root of Krita's pykrita folder and the grimorio_color folder is next to it. Restart Krita after importing.
  • It appears as Broken: open the Plugin Manager, select it and read the error. The most common cause is a Krita version mismatch (the plugin supports Krita 5.3/Qt5 and 6.0/Qt6).
  • Clicking a color does nothing: open a document first; the plugin needs an active view.
  • Create layers does nothing: open a document; the command needs an active document.

Compatibility

The full real test (layer stack, blend modes and lighting rig) runs on Linux with Krita 6.0.4.1 (Qt6). Krita 5.3.4.1 (Qt5) passes the model, bridge, translation and UI tests; the full real re-run is pending while Krita is open and locks the resource database. The plugin is pure Python and does not bundle binaries. Windows and macOS have not been tested.

Color Grimoire es un docker de Krita para guardar los colores de cada OC, la parte del cuerpo, para qué sirve cada color, su opacidad, la receta de capas y la paleta del ambiente. Clic = color de primer plano; clic derecho = fondo.

  • Botón web: abre el Grimorio web en el navegador; ruta local o URL configurable.
  • Foto opcional del OC: se copia a images/ y se muestra en la ficha.

  • Rampas de color: cada zona muestra sombra → base → luz.
  • Traducciones propias: JSON en translations/; el menú crea la plantilla, abre la carpeta y recarga.
  • Vista de escena: los colores clave teñidos por la luz, la sombra y el rebote del ambiente.
  • Crear luces en Krita: grupo de capas de relleno SHADOW/AO/LIGHT/GLOW/BOUNCE con los colores del ambiente.
  • Color Guard: compara el color actual con la paleta del OC, muestra el más cercano y el ΔE, y permite corregirlo con Snap.
  • Instala el ZIP con Tools → Scripts → Import Python Plugins, reinicia Krita, actívalo en Settings → Configure Krita → Python Plugin Manager y reinicia otra vez.
  • El panel aparece en Settings → Dockers → Color Grimoire.
  • Todo se guarda en un JSON local; no hay red ni cuentas. Haz backup con ⋯ → Export JSON….
  • La zona Privado está oculta por defecto; no está cifrada.
  • Probado a fondo con Krita 6.0.4.1; en 5.3.4.1 pasan modelo, puente y UI, pendiente la pasada real completa con Krita cerrado.
