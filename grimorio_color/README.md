# Color Grimoire (Krita plugin)

Version **0.7.0**. Runtime files for the Color Grimoire docker.

Color sheets for characters, scenes and props: configurable palette zones, reusable palette library, layer recipes, multiple environment palettes, Color Guard, JSON and `.gpl` export, private mode and Spanish/English UI. Everything is local; no network, no accounts, no telemetry.

The docker upgrades a 0.4.1 `grimorio.json` automatically and keeps a `grimorio.json.v1.bak` copy. See [`../MIGRATION-0.4.1-TO-0.7.0.md`](../MIGRATION-0.4.1-TO-0.7.0.md) for the step-by-step guide.

See the repository README for install, screenshots, compatibility, data paths and license.
